DHB-XR Tutorial

From install to invariant trajectory adaptation in minutes.

1 Quick Start

Install and run your first encode/decode in three lines.

Install

# PyPI
pip install dhb-xr

# or with pixi
pixi add dhb-xr

Encode and Decode

from dhb_xr.encoder.dhb_dr import encode_dhb_dr
from dhb_xr.decoder.dhb_dr import decode_dhb_dr

# Encode: positions (N,3) + quaternions (N,4 wxyz) -> invariants
enc = encode_dhb_dr(positions, quaternions)

# Decode from a new start pose -> adapted trajectory
dec = decode_dhb_dr(
    enc["linear_motion_invariants"],
    enc["angular_motion_invariants"],
    initial_pose={"position": new_start, "quaternion": new_quat},
)

3 Code Examples

Copy-paste snippets for the most common workflows.

Example 1

Encode a trajectory and verify invariance 

from dhb_xr.encoder.dhb_dr import encode_dhb_dr
import numpy as np

# Your trajectory
positions = np.random.randn(50, 3).cumsum(axis=0) * 0.01
quaternions = np.tile([1, 0, 0, 0], (50, 1))

# Encode
enc = encode_dhb_dr(positions, quaternions)
invariants = enc["linear_motion_invariants"]

# Apply SE(3) transform
offset = np.array([0.1, 0.05, 0])
shifted = encode_dhb_dr(positions + offset, quaternions)

# Invariants are identical!
print(f"Distance: {np.linalg.norm(invariants - shifted['linear_motion_invariants']):.10f}")
# -> 0.0000000000
Example 2

Build a motion database 

from dhb_xr.database import MotionDatabase

db = MotionDatabase()
for traj_pos, traj_quat in my_trajectories:
    db.add(traj_pos, traj_quat, metadata={"task": "pick"})

# Retrieve nearest -- works at any workspace offset
results = db.retrieve(query_pos, query_quat, k=5)
